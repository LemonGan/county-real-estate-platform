## 本轮修复

1. 资讯作者名字段兼容

   后端返回的是 `author_name`，前端部分页面使用了 `author`。已在资讯列表和详情页统一兼容 `author || author_name`，避免作者名显示为空。

2. 资讯详情失败空态

   新增“资讯暂时无法查看”的空状态，避免资讯不存在或已下架时只剩空白页面。

3. 意见反馈页未登录体验

   未登录时不再先弹出接口鉴权提示再显示空白历史区，改为页面内登录卡片提示，并隐藏历史列表区。

4. 反馈分类中文展示

   我的反馈列表改为显示中文分类名，而不是原始分类 key。
