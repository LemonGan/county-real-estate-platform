## 🚀 部署步骤

### 第一步：下载微信开发者工具

访问 https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html 下载稳定版

### 第二步：登录开发者工具

1. 打开微信开发者工具
2. 使用微信扫码登录（需要管理员微信扫码）
3. 选择 **小程序** 类型

### 第三步：导入项目

1. 点击「导入项目」
2. 项目目录：`D:\study\python\buyHouse\county-real-estate-platform\miniprogram`
3. AppID 会自动识别为 `wxedc565a494463d97`
4. 点击「导入」

### 第四步：检查本地调试

确认以下功能正常：
- 首页房源列表加载
- 经纪人列表
- 新闻资讯
- 预约看房
- 个人中心登录

### 第五步：配置服务器域名 ⚠️ 关键

登录微信公众平台：https://mp.weixin.qq.com

1. 进入 **设置 → 开发设置 → 服务器域名**
2. 配置以下域名：

| 类型 | 域名 |
|------|------|
| request合法域名 | `https://api.xqfc.cn` 或 `http://8.138.129.142` |
| socket合法域名 | `wss://api.xqfc.cn` 或 `ws://8.138.129.142` |
| uploadFile合法域名 | `https://api.xqfc.cn` |
| downloadFile合法域名 | `https://api.xqfc.cn` |

> 💡 如果用 IP 访问，需要在「调试基础库」关闭域名校验（仅开发调试用）

### 第六步：上传代码

1. 在开发者工具点击 **上传** 按钮
2. 填写版本号：`1.0.0`
3. 填写备注：首次发布
4. 点击「上传」

### 第七步：提交审核

1. 登录微信公众平台
2. 进入 **版本管理**
3. 找到刚上传的版本，点击「提交审核」
4. 填写审核信息：
   - 功能页面：首页、房源列表、经纪人、资讯、个人中心
   - 测试账号：可选填写
5. 等待审核（通常1-7天）

### 第八步：发布上线

审核通过后，在公众平台点击「发布」即可上线。

---

## ⚠️ 注意事项

1. **域名HTTPS**：生产环境建议配置HTTPS域名（可用nginx反向代理）
2. **ICP备案**：小程序上线需要域名已完成ICP备案
3. **支付功能**：如需微信支付，需要额外申请商户号

修改代码后重新上传新版本，重复第六、七、八步即可。
